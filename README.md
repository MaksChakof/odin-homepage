# Homepage

Адаптивная страница-портфолио — проект курса [The Odin Project](https://www.theodinproject.com/lessons/node-path-advanced-html-and-css-homepage) (Advanced HTML and CSS). Макет курса дан в трёх размерах: компьютер, планшет, телефон.

**Живая страница:** https://makschakof.github.io/odin-homepage/

## Что внутри

- **Сначала телефон (mobile-first):** базовые стили — для узкого экрана, `@media (min-width: …)` добавляют колонки. Проекты: 1 колонка → 2 (от 640px) → 3 (от 1024px). Шапка и контакты встают в две колонки от 768px.
- Контейнер `width: min(100% - 2.5rem, 67rem)`: на телефоне поля по 20px, на большом экране — 1072px по центру.
- Скриншоты проектов в двух размерах через `srcset` и `sizes`, рамка `aspect-ratio: 16 / 10` + `object-fit: cover`.
- Скошенный синий фон шапки — `::before` с `clip-path`.
- Значки GitHub и «открыть» описаны один раз в SVG-наборе и подставляются через `<use>`.
- Синий из макета `#0891b2` с белым текстом даёт 3.68:1 (ниже нормы AA), заменён на `#0e7490` — 5.36:1.
- Вместо фото в шапке — картинка с кодом, контакты — только GitHub.
- Lighthouse: Accessibility, Best Practices, SEO — 100. Проверено на ширинах от 320 до 1920px: горизонтальной прокрутки нет.
